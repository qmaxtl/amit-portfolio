# Amit Kumar Gupta — Bespoke Digital Lab & Portfolio (Kernel 01)

> **"I don't just build digital products. I create systems, experiences, and businesses."**

A bespoke, Awwwards-caliber personal portfolio designed and engineered for **Amit Kumar Gupta**, positioning him at the intersection of **AI, Software, SaaS, Automation, Product Building, and Creative Engineering**.

## ✦ Core Creative Philosophy

- **The Creative Concept:** *"The Digital Lab (Kernel 01)"* — An explorable cyber-monolithic control terminal where projects are treated not merely as static cards, but as living **systems, objects, and worlds**.
- **Visual Identity:**
  - Base: Obsidian Carbon Black (`#08090A`)
  - Elevated Surfaces: Deep Void Slate (`#11141A`, `#181D26`) with hairline precision rules (`rgba(255,255,255,0.08)`)
  - Signal Highlights: Electric Cyan (`#00F0FF`), Cobalt System (`#3B82F6`), Active Emerald (`#10B981`), and Violet (`#8B5CF6`)
- **Signature Visual ("The Neural Lattice Core"):**
  - Bespoke **Three.js WebGL** 3D interactive core with procedural icosahedron geometry, orbiting particle data fields, cursor-tracking physics, and scroll reactivity.
  - Automated graceful fallback to a high-performance **Canvas2D** generative constellation network for low-power devices and reduced-motion preferences.
- **Micro-Interaction & Motion Language:**
  - **Lenis** smooth inertia scrolling.
  - Contextual **magnetic custom cursor** (morphs between default pinpoint, `VIEW`, `OPEN ↗`, and `DRAG` on desktop; automatically disabled on touch devices).
  - **Web Audio API** procedural micro-synthesizer (tactile clicks, section frequency sweeps, harmonic completion chords) — muted by default with a live HUD toggle.

## ✦ Getting Started

### 1. Set as Active Workspace
To work directly on this portfolio in your editor:
```bash
# Recommended active workspace directory:
C:\Users\Amit\.gemini\antigravity\scratch\amit-portfolio
```

### 2. Development Server
```bash
npm run dev
# Open http://localhost:3000 in your browser
```

### 3. Production Build & Test
```bash
# Type check:
npm run typecheck

# Production build:
npm run build

# Start production server:
npm run start
```

## ✦ Customizing Personal Information

All personal data, links, case studies, and capabilities are centralized in a single typed configuration file:
```typescript
src/data/portfolio-content.ts
```

To update your contact handles, simply replace the marked placeholders:
- `contact.email`: Update to your primary email address.
- `contact.github`: Link to your GitHub profile.
- `contact.linkedin`: Link to your LinkedIn profile.
- `contact.x`: Link to your X / Twitter handle.
